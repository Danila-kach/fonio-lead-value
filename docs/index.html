What is a Fonio signup worth?

The lead-value model, scored 72 hours after signup, on the February–March 2026 test signups the model was not trained on. Switch platform, drag the slider, try the calculator.

Platform

1. What the platform is told a signup is worth

Today every signup is sent as equal. With the model, each signup carries its own value in euros. Every bar is one test signup, sorted by the value the model sends; the dashed line is today. Hover a bar to see what that signup did and what it really brought.

2. If the platform chased only the best signups

Drag to pick how many of the signups, highest value first, and see how much of the real revenue and how many of the paying customers sit inside that group. Today any group of the same size holds a share equal to its size.

3. Thirds of signups by predicted value

The signups split into three equal groups by the value the model sends, with what they really did and what they look like.

4. Value calculator: what would the model send for this signup?

Describe a signup as it looks 72 hours after signup. The model gives the chance of paying, the expected revenue if they pay, and the value (chance × revenue). The bars show which facts pushed the chance up or down.

5. The weights the model learned

Step 1, "will they pay?": positive pushes the chance up. Step 2, "if they pay, how much?": in euros. Weights are comparable within a column because every feature was put on the same scale before training.

6. Every test signup

Filter and sort. Value is what the model would send; "really brought" is the revenue over 180 days.
